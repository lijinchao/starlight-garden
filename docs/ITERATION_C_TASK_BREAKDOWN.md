# 星光花园 - 迭代 C 目标对齐与验证清单

## 文档目标

本文件用于把当前版本从“可连续体验的 Pre-MVP 原型”推进到“有次日回访理由的轻量 MVP 骨架”。

迭代 C 只做每日回访与日常目标的最小闭环，不接入广告 SDK，不做社交，不扩展大型装饰系统。

---

## 1. 迭代 C 目标

本轮只做一件事：

> 让玩家每天回来时都有一个轻量、可完成、可领取的目标。

本轮不做：

- 广告 SDK 真实接入
- 好友、排行榜、分享裂变
- 大型花园装饰系统
- 新增剧情章节
- 大规模关卡扩展

---

## 2. 产品目标对齐

### 2.1 玩家视角目标

玩家在这一版中应能明确感知：

1. 每天进入游戏都有“今日花礼”可查看。
2. 玩 1 局、收获 1 次、获得花语碎片都会推进每日目标。
3. 完成全部每日目标后能领取一次温和奖励。
4. 即使不推进主线，也有一个低压力的回访理由。

### 2.2 产品验收目标

- 每日任务在日期变化时自动刷新。
- 三个基础任务都能由真实玩法事件推进。
- 每日礼包每天只能领取一次。
- 领取奖励会进入现有资源流，不创建孤立货币。

---

## 3. 目标映射表

| 迭代项 | 服务的产品目标 | 用户感知结果 | 可验证方式 |
|------|------|------|------|
| 每日任务数据 | 增强内容留存 | 每天有可完成目标 | 自动化测试 |
| 今日花礼入口 | 增强内容留存 | 主菜单可查看今日进度 | 手动验证 |
| 玩法事件接入 | 闭合主循环 | 玩局、收获、花语都推进任务 | 自动化测试 |
| 每日礼包领取 | 强化治愈体验 | 完成后获得轻奖励 | 自动化测试 + 手动验证 |
| Harness 扩展 | 确保方向正确 | 后续迭代不会绕过每日验证 | Harness 检查 |

## 4. 本轮要补齐的系统

### P1-1 每日任务服务

目标：

- 提供日期刷新、任务进度、完成判定和礼包领取。

最小规则：

- 每日任务 3 个：
  - 完成任意 1 局
  - 收获任意 1 朵花
  - 获得任意 1 个花语碎片
- 三个任务全部完成后，可领取今日花礼。
- 今日花礼奖励：`20` 星光 + `1` 个红玫瑰花种。
- 同一自然日只能领取一次。

测试点：

- 默认存档包含每日数据。
- 日期变化时任务重置。
- 每日事件能推进对应任务。
- 未完成全部任务时不可领取。
- 完成后可领取且不可重复领取。

---

### P1-2 今日花礼 UI

目标：

- 玩家可在主菜单打开今日花礼，查看任务和领取奖励。

实现要求：

- 主菜单增加“今日花礼”入口。
- 页面展示日期、3 个任务进度、完成状态和奖励说明。
- 可领取时按钮可用，领取后显示已领取。
- 页面可返回主菜单。

手动验证：

- 重置存档后进入今日花礼。
- 完成一局后任务进度更新。
- 收获花朵后任务进度更新。
- 获得花语碎片后任务进度更新。
- 全部完成后可领取奖励。

可评估结果：

- 玩家能在主菜单直接看到今日目标入口。
- 玩家完成一个真实玩法动作后，能在今日花礼中看到对应进度变化。
- 今日花礼奖励能回到星光和花园资源流，而不是形成孤立系统。

---

### P1-3 玩法事件接入

目标：

- 每日任务必须由真实玩法推进，而不是调试按钮。

接入点：

- 胜利或失败结算后记录 `play_level`。
- 花园收获后记录 `harvest_flower`。
- 花语碎片发放后记录 `collect_flower_fragment`。

测试点：

- 胜利结算会推进完成任意 1 局任务。
- 失败结算也会推进完成任意 1 局任务。
- 花园收获会推进收获任务。
- 花语碎片发放会推进碎片任务。

---

## 5. 数据与资源流

本轮资源流：

`每日登录 -> 查看今日花礼 -> 完成玩法事件 -> 领取星光/花种 -> 继续闯关或花园成长`

资源来源：

- 今日花礼

资源用途：

- 星光用于续关或开局祝福。
- 花种进入花园种植、合成、收获链路。

资源反馈：

- 今日花礼 UI 展示任务进度。
- 领取后 Toast 明确显示奖励。

---

## 6. UI / 交互要求

- 主菜单增加“今日花礼”按钮。
- 今日花礼页面可返回主菜单。
- 任务显示 `当前进度/目标进度`。
- 全部完成前显示“完成今日目标后领取”。
- 领取后显示“今日已领取”。

---

## 7. 验证清单

### 自动化测试

- 每日默认存档结构。
- 日期刷新重置任务。
- 每日事件推进任务。
- 未完成不可领取。
- 完成后领取奖励。
- 重复领取失败。

### 手动验证

- 主菜单进入今日花礼。
- 完成一局后查看任务进度。
- 收获花朵后查看任务进度。
- 获得花语碎片后查看任务进度。
- 全部完成后领取今日花礼。

### 评估问题

1. 玩家是否能在 10 秒内理解今天要做什么？
2. 每日目标是否推动主循环，而不是绕开主循环？
3. 奖励是否能回到星光和花园资源流？
4. 如果移除每日系统，次日回访理由是否明显变弱？

---

## 8. 完成定义

当以下条件都满足时，迭代 C 才算完成：

1. 每日任务数据写入并读取自存档。✅
2. 日期变化会重置每日任务。✅
3. 三类玩法事件能推进对应任务。✅
4. 今日花礼入口和 UI 可用。✅
5. 今日奖励可领取且不可重复领取。✅
6. 自动化测试覆盖每日资源流。✅
7. 手动验证文档包含每日验证步骤。✅
8. `./run_harness.sh` 通过。✅
