# 星光花园 - 手动验证指引

## 适用范围

本指引用于手动验证截至迭代 L 已交付的核心功能：

- 统一结算
- 配置化奖励
- 花园合成
- 星光第二用途
- 失败保底与连续失败鼓励
- 花语碎片与花语日记
- 每日任务与今日花礼
- 花园装饰与氛围值
- 主菜单渐进解锁与结算降噪

## 验证 1：通关奖励是否按结算发放

目标：

- 验证胜利后会统一发放星光、花种、首通奖励

步骤：

1. 从主菜单进入游戏
2. 完成当前关卡
3. 观察胜利弹窗
4. 返回主菜单或进入花园查看资源变化

预期结果：

- 胜利弹窗显示分数、星级和奖励摘要
- 首次通关时会看到“首通奖励已发放”
- 玩家星光增加
- 花园背包中出现本关奖励花种
- 当前关卡解锁到下一关
- 如果本局推进了恢复阶段，进入花园时会先看到一次短暂的恢复到达提示

---

## 验证 2：关卡奖励是否有差异

目标：

- 验证不同关卡有不同奖励追求

步骤：

1. 完成较前面的关卡，例如 `1-3`
2. 再完成中段或后段关卡，例如 `10` 或 `13+`
3. 对比结算弹窗与花园背包内容

预期结果：

- 不同关卡奖励花种类型不同
- 中后段关卡星光奖励更高
- 后段关卡花种数量更多

---

## 验证 3：花园种植与收获

目标：

- 验证通关拿到的花种能进入花园成长闭环

步骤：

1. 通关任意一关获得花种
2. 返回主菜单，进入“我的花园”
3. 点击空花盆进行种植
4. 等待成长完成后再次点击花盆
5. 收获花朵

预期结果：

- 背包花种数量减少
- 花盆进入成长状态
- 成熟后可收获
- 收获后获得星光
- 花盆恢复为空闲
- 花园右侧恢复区的预览画面与下一步提示会随局数阶段变化
- 空花盆本身也会从“枯叶/待唤醒”逐步变成“发芽/开花/微光”

---

## 验证 4：花园合成

目标：

- 验证两个同等级同类型花种可合成为更高一级

步骤：

1. 通过闯关获得至少 2 个同类型同等级花种
2. 进入花园背包
3. 找到出现“合成”按钮的条目
4. 点击“合成”

预期结果：

- 原等级材料减少 2 个
- 新等级花种增加 1 个
- 出现合成成功提示
- 同一花种的高等级条目出现在背包中

补充观察：

- Lv.2、Lv.3 花朵收获星光应明显高于 Lv.1

## 验证 5：星光祝福（开局加步数）

目标：

- 验证星光拥有第二个明确用途

步骤：

1. 保证账号内至少有 `12 ✨`
2. 从主菜单点击“开始游戏”
3. 在弹出的“星光祝福”确认框中选择确认
4. 进入关卡后观察步数

预期结果：

- 进入关卡前弹出确认框
- 扣除 `12 ✨`
- 本局初始步数比默认值多 `3`
- 若取消，则正常步数开局
- 若星光不足，则不会进入付费确认流程

## 验证 6：失败保底奖励

目标：

- 验证失败后不会“白玩”

步骤：

1. 进入关卡
2. 故意消耗完步数但不完成目标
3. 观察失败弹窗与资源变化

预期结果：

- 弹出“休息时刻”弹窗
- 弹窗显示完成度和安慰奖励
- 玩家星光增加
- 前三局只出现“回花园看看”，不出现继续挑战消费入口

## 验证 7：连续失败鼓励

目标：

- 验证连续失败两次后有额外缓冲

步骤：

1. 连续两局都主动失败
2. 第二次失败时观察弹窗与花园背包

预期结果：

- 第二次失败弹窗显示“连续失败鼓励已触发”
- 第二次失败时奖励星光更多
- 花园背包额外获得 1 个鼓励花种

## 验证 8：失败后继续挑战

目标：

- 验证续关扣星光并恢复步数

步骤：

1. 在失败弹窗中选择“继续挑战”
2. 保证当前星光足够支付续关消耗

预期结果：

- 扣除对应星光
- 恢复 `5` 步
- 关卡继续进行，不会重新开局

## 验证 9：花语碎片与花语日记

目标：

- 验证闯关和失败都会推进花语收集，且玩家能在日记页看到进度

步骤：

1. 重置存档
2. 从主菜单进入“花语日记”
3. 观察 6 种基础花的碎片进度
4. 返回主菜单并通关第 1 关
5. 在胜利弹窗中观察花语碎片奖励
6. 返回“花语日记”查看红玫瑰进度
7. 再通关或失败若干次，直到红玫瑰达到 `5/5`

预期结果：

- 初始日记页显示 6 种基础花
- 未解锁花语只显示碎片进度，不显示完整花语
- 通关结算显示获得对应花语碎片
- 失败结算也显示获得对应花语碎片
- 达到 `5/5` 后，日记页显示完整花语文案

## 验证 10：每日任务与今日花礼

目标：

- 验证玩家每天有轻量回访目标，且奖励能回到星光和花园资源流

步骤：

1. 重置存档
2. 从主菜单进入“今日花礼”
3. 观察 3 个每日任务的初始进度
4. 返回主菜单，完成或失败任意 1 局
5. 再次进入“今日花礼”查看“完成任意 1 局”进度
6. 进入花园并收获任意 1 朵成熟花
7. 通关或失败获得任意花语碎片
8. 三个任务全部完成后点击“领取今日花礼”

预期结果：

- 今日花礼显示当前日期
- 三个任务分别显示当前进度和目标进度
- 完成玩法事件后，对应任务进度更新
- 全部完成前不可领取
- 全部完成后可领取 `20 ✨ + 红玫瑰花种 x1`
- 同一天重复点击领取不会再次发放奖励

目标：

- 验证星光能转化为可见花园装饰，并提升氛围值

- 重新进入花园后已点亮状态保持

## 验证 12：主菜单渐进解锁与结算降噪

目标：

- 验证前三局优先感知“花园恢复”，Meta 系统不会同时争夺注意力

步骤：

1. 重置存档
2. 返回主菜单，观察入口
3. 点击“开始游戏”，确认是否弹出星光祝福
4. 完成或失败第 1 局，观察结算弹窗中的花园恢复描述
5. 返回主菜单，观察花园恢复阶段是否变化
6. 进入“我的花园”，确认是否只看到恢复信息、种植和收获
7. 再完成或失败第 2 局与第 3 局，每局后都返回菜单或花园观察恢复阶段
8. 对照结算、主菜单和花园页，确认三处都在说明同一个“修好的角落”
9. 第 3 局结束后，返回主菜单，观察花语日记和今日花礼入口
10. 第 4 次点击“开始游戏”前，在星光足够时观察是否弹出星光祝福

预期结果：

- 新存档主菜单不显示“花语日记”和“今日花礼”
- 前 3 局点击“开始游戏”不会弹出星光祝福确认
- 前 3 局结算首层会提示花园恢复阶段
- 第 1、2、3 局结束后，菜单或花园中的恢复阶段会发生变化
- 第 1、2、3 局结束后，结算、主菜单和花园会一致提示“第一簇新芽 / 第一朵花 / 门前微灯”等具象变化
- 前 3 局胜利或失败后，点击主按钮会直接进入花园
- 前 3 局花园页不显示合成按钮和装饰购买列表
- 前 3 局失败弹窗不显示继续挑战消费入口
- 普通花语碎片进度不占用首层弹窗
- 胜利弹窗不显示“双倍奖励”按钮
- 第 3 局完成后，主菜单开始显示“花语日记”和“今日花礼”
- 累计完成 3 局且星光足够后，开始游戏会弹出星光祝福确认
- 累计完成 3 局后，花园页开始显示合成按钮与装饰购买区

## 验证 13：局内爽感差异化

目标：

- 验证前 5 关是否已经具备一个明确的、主题化的局内爽点，而不是继续停留在普通收集三消

步骤：

1. 进入第 1 关，观察当前目标文案
2. 在前 5 关内尝试制造一次 4 连
3. 观察棋盘上是否出现“清风唤醒”反馈
4. 记录 4 连前后目标进度是否出现额外推进
5. 完成或失败该局，观察结算首层是否说明本局唤醒了哪个角落
6. 连续检查第 2-5 关，确认目标描述仍保持“唤醒 / 点亮某个角落”的主题表达

预期结果：

- 前 5 关的 HUD 目标不只显示花朵收集，而是明确指向某个花园角落
- 4 连时会出现一次“清风唤醒”反馈，而不是传统炸弹式命名
- `清风唤醒` 会真实推进当前目标，不只是播一段动画
- 结算会说明“清风唤醒了哪个角落”或“这一局正在唤醒哪个角落”
- 前 5 关整体感知更接近“照料花园”，而不是纯颜色收集

## 验证 14：落叶与方向清风路径

目标：

- 验证第 2-5 关不再只有目标数字变化，并确认普通消除与方向四连都能可靠推进

步骤：

1. 进入第 2 关，确认棋盘上有 3 处落叶，HUD 同时显示花朵和落叶进度
2. 在落叶自身或上下左右位置完成一次普通三连
3. 确认邻近落叶消失，远处落叶保持不变
4. 制造一次横向四连，观察清风是否贯穿整行并扫开同一行落叶
5. 制造一次纵向四连，观察清风是否贯穿整列并扫开同一列落叶
6. 只完成花朵收集，确认落叶未扫净时不会提前通关
7. 依次进入第 3-5 关，确认落叶数量与空间布局发生变化

预期结果：

- 普通三连提供稳定的邻近清扫，不依赖随机四连才能过关
- 横向和纵向四连产生不同路径，路径以宽风带和方向文字呈现
- 两个交叉三连不会误判为横向或纵向四连
- 普通关收集满花朵即可结算胜利，落叶是可选的额外进度；每日风庭仍需扫净落叶才能通过
- 第 2-5 关分别有 3、4、5、6 处落叶且布局不同

## 验证 15：每日风庭与晨露连锁

目标：

- 验证迭代 L 的每日同题、晨露花苞十字连锁和推荐方向延伸是否真的形成“先观察再行动”的空间解题，而不只是换一批落叶坐标

步骤：

1. 记下今天日期，打开今日花礼页，确认上半区显示“今日风庭”、布局名、推荐风向和开始按钮
2. 开始今日风庭，确认棋盘上除落叶外还有高对比的晨露花苞标记，且花苞都位于落叶层中
3. 在花苞自身或上下左右位置完成一次普通三连，确认花苞被扫开后十字扩散并继续清扫邻域落叶
4. 当扩散命中另一枚花苞时，确认连锁按顺序继续，并出现“晨露连锁 xN”反馈
5. 制造一次与推荐风向相同的四连，确认花苞十字清扫范围比普通情况多延伸一圈
6. 观察失败或通关弹窗：失败是否提示重试会保留同一布局与初始棋盘，通关是否展示最大连锁
7. 重试一次，确认同一日期的初始棋盘、落叶和花苞位置完全一致
8. 把系统日期改到相邻一天，确认挑战 ID、布局或变换发生变化，且昨日最佳不会串入新日期

预期结果：

- 一天之内布局、落叶、花苞与初始棋盘固定，重试可复盘而不是靠刷开局
- 晨露花苞在落叶层上可见，扫开后十字扩散，命中其他花苞会按顺序继续连锁
- 推荐方向四连让花苞清扫范围额外延伸，但不成为唯一通关条件
- 每日挑战不发放普通关卡星光或花种，也不推进线性关卡
- 相邻日期会生成不同布局或变换，本日成绩与日期绑定
- 连锁反馈清楚且不刺眼，动画期间不能重复输入，胜负只在整回合连锁结算后判定

## 验证 16：消除 → 花园角落可见变化（迭代 M / M2）

目标：

- 验证消除与花园之间是否形成“我清掉的东西让花园变了”的连续因果，而不是只跳数字

步骤：

1. 进入任意普通关，观察棋盘下方是否出现“正在照料：<角落>”与三个未点亮的阶段标记
2. 连续完成几次三连，观察每次消除后该指示器是否出现短促反馈
3. 当主目标推进到约三分之一、三分之二时，确认阶段标记依次点亮并显示“亮了一点”
4. 完成本局主目标，确认三个标记全部点亮并显示“这一局把这里照料好了”
5. 进入每日风庭，确认需要同时完成花朵目标并扫净落叶，指示器才进入完成阶段

预期结果：

- 每次有效消除都会产生一次可被记录的“花园角落推进”事件
- 花园角落的三个阶段与主目标（以及每日的必需落叶）进度一致
- 玩家在第 1 局结束后能指出“我让哪里变了”

## 验证 17：一局情绪节奏与完成高潮（迭代 M / M3）

目标：

- 验证一局是否具备“接近目标时升温、完成时释放”的起伏，而不是全程一条平线

步骤：

1. 进入普通关，确认开局背景平静、状态文案为常规目标说明
2. 把主目标推进到约七成，确认出现“风渐渐起来了”文案且背景转暖
3. 继续推进到接近完成，确认出现临门档文案与更明显的反馈
4. 故意留少量步数，确认步数偏低时也会升温
5. 完成本局，确认出现明确高潮（文案、背景暖化、花园角落面板放大、胜利音效）
6. 重开一局，确认节奏与背景视觉已重置，不残留上一局的高潮状态

预期结果：

- 接近目标或剩余步数偏低时会触发分级升温，并记录 `rhythm_escalated` 事件
- 同一档不会重复升温
- 完成时触发一次明确高潮并记录 `level_climax` 事件
- 全过程是“升温与释放”，没有任何惩罚式反馈

## 验证 18：结算的情绪回应（迭代 M / M4）

目标：

- 验证结算首层是否回应“本局刚发生的事”，而不是只报数字或通用安慰

步骤：

1. 通关一局（先不追求完美），观察胜利弹窗第一句是否指认本局照料的花园角落
2. 再通关一局并把花园角落推到完成阶段，确认第一句变成“整片照料亮了”
3. 故意失败一局，确认失败弹窗第一句同样回应本局照料目标，且语气是安抚而非指责
4. 在晨露连锁达到 2 连以上后失败，确认第一句会提到那次连锁
5. 对比结算中的奖励数字，确认文案变化没有改动任何奖励数值

预期结果：

- 结算首层第一句来自 `SettlementService.format_emotional_reply()`，绑定本局实际发生的事
- 胜利与失败两条路径都有情绪回应
- 奖励、首通、碎片与星光发放与改动前一致

## 验证 19：具名照料对象（迭代 N / 方向 A）

目标：

3. 持续到亲密度满一个阶段，确认它进入「初醒」并说出它的话

预期结果：

- 面板显示照料对象的名字、阶段符号（🌙→🌱→🌸→✨）、亲密度与最近回应
- 每次有效消除产生 `companion_fed` 事件
- 状态跨局留存，重置后回到初始
- 玩家能说出对象的名字，并描述“它因为我变了”

## 验证 20：A-real 照料对象（迭代 O）

目标：

- 验证照料对象是否真的“有需要、有自主、有取舍”，而不是一个被动计量表

步骤：

1. 进入普通关，确认面板写出它**当前想要什么**（光 / 水 / 陪伴）
2. 观察三个需要的数值，确认请求指向数值最低的那个
3. 只消除与请求不同颜色的花，确认对应需要上升但请求没有马上被满足
4. 再消除请求对应的颜色，确认出现“满足”的更强回应
5. 关闭游戏等待超过 5 分钟再进入（或直接改系统时间），确认首次进入关卡时出现“你不在的时候……”的回访观察
6. 观察长时间不进入时它想要的东西会变，而不是永远同一个

预期结果：

- 面板显示具体请求与三个需要，而不是抽象进度条
- 不同颜色喂不同需要；命中请求有更强回应
- 需要随时间下降但保留下限，不制造“不登录就内疚”
- 离开超过阈值会生成回访观察，并且只展示一次
- 为了它而改变出牌顺序是可感知的取舍

## 验证 22：不可移动石块（迭代 P / B-3）

目标：

- 验证石块是否真的构成空间约束，并且能被可靠地清除

步骤：

1. 进入第 6 关，确认棋盘上有 🪨 石块，HUD 显示“清除石块 x/y”
2. 尝试把石块和旁边的花交换，确认石块不能移动
3. 在石块旁边完成一次三连，确认石块只是**裂开**（变红、裂痕）并提示；**再消一次也击不碎**，石块停在裂开状态
4. 观察击碎后上方的花落在石块原来的位置上方，不会“穿过”石块
5. 把四连凑在石块所在的**同一排**留下清风块，再点它扫过整行，确认同一排两端的石块被一起击碎，且 HUD 的“清除石块 x/y”同步 +2（只有清风能击碎，击碎必须计入进度）
6. 点击清风块触发后，观察掉落补牌是否立刻把新凑成的三连继续消掉，棋盘上不应残留“已经三连却不消”的位置
7. 清光全部石块，确认此时才通关

预期结果：

- 石块不可交换、不参与匹配、不随下落移动
- 相邻消除只能把石块敲裂，只有清风能击碎
- 石块把一列分成上下两段，各自独立下落
- 清光全部石块前不能通关

## 验证 23：花园回报层——因果落到具名角落（迭代 P / B-7）

目标：

- 验证“清光哪一处石块”会变成花园里持久、可见的一处恢复

步骤：

1. 从主菜单进入第 6 关并通关（核心目标：清光全部石块）
2. 看胜利结算首句，确认点名了本局照料的角落（如「石阶小径」）
3. 回主菜单 → 进入「我的花园」，确认首屏出现“已点亮 1 处角落：「石阶小径」”，并且花园上排多出一个带花与名字的**可见花位标记**
4. 确认这个标记落在固定的花园位置上，而不是随机漂浮
5. 回到主菜单重新进入花园，确认这处角落和标记仍在
6. 再打通第 6 关一次，确认不会变成“已点亮 2 处角落”

预期结果：

- 通关会把该关的具名角落写进花园，且跨存档保留
- 花园首屏能看见自己打通的那一处，名字与结算一致
- 重玩已通关的关卡不会重复恢复同一角落

## 推荐验证顺序

建议一次完整回归按以下顺序执行：

1. 重置存档
2. 通关 1 关，检查胜利结算
3. 进入花园，种植并收获
4. 再通关拿到同类花种，验证合成
5. 从主菜单测试星光祝福
6. 故意失败，验证保底奖励
7. 连续第二次失败，验证鼓励奖励
8. 测试失败后继续挑战
9. 查看花语日记，验证碎片进度和解锁状态
10. 查看今日花礼，验证每日任务和领取状态
11. 进入花园购买装饰，验证氛围值和存档保持
12. 重置存档后验证前三局花园恢复反馈与入口减法
13. 打开今日花礼，完成或重试一次今日风庭，验证同日可复现与晨露连锁
14. 在普通关观察花园角落指示器随消除推进并点亮三阶段
15. 在一局中推进到接近目标，观察背景升温与完成高潮
16. 结算后阅读弹窗第一句，确认它回应了本局实际发生的事
17. 观察棋盘下方的照料对象，确认消除会喂它、它会回应、并且跨局留存
18. 观察它的当前请求与三个需要，确认按颜色喂食会改变请求，并验证离开后的回访观察
19. 体验第 6-8 关，确认一局只有一个目标、步数紧张、需要主动规划清风路径
20. 体验第 6-8 关的石块：不可交换、相邻消除击碎、分段下落、清光才通关
21. 在主菜单点“选择关卡”，重玩一个已通关的旧关卡，确认可以回到之前的关
