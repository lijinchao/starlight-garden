## 🎯 游戏愿景

> 让每一位忙碌的女性，在下班或休息的碎片时间，都能通过《星光花园》获得**5分钟的治愈时光**。

### 核心价值主张
- 🌸 **治愈体验**：没有失败，只有休息时刻
- ✨ **快速反馈**：3秒内获得消除快感
- 💜 **情绪价值**：收集花语，获得情感共鸣
- ⏱️ **碎片友好**：随时随地，想玩就玩

## 🎮 核心玩法设计

### 游戏循环

```
┌─────────────────────────────────────────────────────────────┐
│                      核心游戏循环                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐ │
│   │ 消除关卡 │ → │ 获取奖励 │ → │ 合成花朵 │ → │ 装饰花园 │ │
│   └─────────┘    └─────────┘    └─────────┘    └─────────┘ │
│        ↑                                              │     │
│        └──────────────────────────────────────────────┘     │
│                                                             │
│   副循环：收集花语 → 解锁故事 → 情感共鸣 → 持续游玩         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 消除玩法（核心）

#### 基础规则
- **网格大小**：7×7
- **消除方式**：交换相邻元素，形成3个及以上连线
- **消除条件**：横/竖/斜线3连即可消除
- **下落机制**：消除后上方元素自然下落

#### 元素设计
| 元素类型 | 数量 | 功能 |
|---------|------|------|
| 基础花朵 | 6种 | 红玫瑰、蓝勿忘我、紫薰衣草、黄向日葵、白茉莉、粉樱花 |
| 流星 | 特殊 | 消除整行或整列 |
| 彩虹花 | 特殊 | 可匹配任何颜色 |
| 星光炸弹 | 特殊 | 消除周围3×3范围 |

#### 关卡目标
| 目标类型 | 示例 | 难度 |
|---------|------|------|
| 收集指定数量 | 收集20个红玫瑰 | ⭐ |
| 达到指定分数 | 获得5000分 | ⭐⭐ |
| 限时挑战 | 60秒内完成 | ⭐⭐⭐ |
| 特殊消除 | 触发3次连锁 | ⭐⭐⭐ |

#### 失败机制（重要：无负向反馈）
```
传统三消：步数用完 → 失败 → 重新开始 → 负面情绪

星光花园：步数用完 → "休息时刻" → 获得安慰奖励 → 鼓励继续
```

**休息时刻设计**：
- 显示治愈语录："星星也需要休息，明天继续闪耀吧~"
- 获得10%进度奖励（不归零）
- 可选择：看广告继续 / 休息一下

---

### 合成养成玩法

#### 花朵等级
```
Lv.1 种子 → Lv.2 花苞 → Lv.3 绽放 → Lv.4 盛放 → Lv.5 星光花
```

#### 合成规则
- 2个同等级花朵 → 合成1个高一级花朵
- 合成需要时间（可加速）
- 高级花朵产出更多星光

#### 花园系统
- **花盆位**：初始4个，可扩展至16个
- **装饰物**：长椅、喷泉、灯笼、围栏
- **主题皮肤**：春日花园、夏夜星空、秋叶庭院、冬日暖阳

### 花语收集系统

#### 花语设计
| 花朵 | 花语 | 情绪 |
|------|------|------|
| 红玫瑰 | "热烈的爱，永不褪色" | 热情 |
| 蓝勿忘我 | "请记得，我一直在" | 思念 |
| 紫薰衣草 | "等待也是一种浪漫" | 宁静 |
| 黄向日葵 | "向着光，就不会有阴影" | 阳光 |
| 白茉莉 | "纯洁的心，最珍贵" | 纯真 |
| 粉樱花 | "短暂的美，值得珍惜" | 浪漫 |

#### 收集机制
- 消除时随机掉落花语碎片
- 集齐5个碎片 → 解锁完整花语
- 收集全部花语 → 解锁"治愈日记"

## 💰 商业化设计

### 广告变现（核心）

#### 激励视频广告
| 场景 | 广告价值 | 用户动机 |
|------|---------|----------|
| 失败后继续 | 获得额外5步 | 避免重玩 |
| 获取双倍奖励 | 奖励翻倍 | 快速收集 |
| 解锁特殊道具 | 获得彩虹花/流星 | 通关辅助 |
| 每日免费礼物 | 额外奖励 | 白嫖心理 |
| 加速合成 | 减少等待时间 | 节省时间 |

#### 插屏广告
- 关卡失败后展示（可跳过）
- 每3-5关展示一次
- **频率控制**：不影响核心体验

#### Banner广告
- 花园界面底部
- 不影响操作区域

### 轻度内购（补充）

| 商品 | 价格 | 内容 |
|------|------|------|
| 去广告特权 | 6元 | 永久去除插屏广告 |
| 月卡 | 12元/月 | 每日星光+专属花园装饰 |
| 新手礼包 | 6元 | 星光+道具+装饰 |
| 节日礼包 | 12-30元 | 限定装饰+花语 |

### 变现预期
- **ARPU**：0.3-0.5元（广告为主）
- **付费率**：5-8%（轻度内购）
- **日活目标**：10万+（上线3个月）

## 🎨 美术风格

### 视觉定位
**"梦幻治愈风"** - 柔和色调+星光特效

### 主色调（马卡龙色系）
```
🌸 粉色系：#FFB6C1 (浅粉) / #FF69B4 (热粉) / #FFC0CB (粉红)
💜 紫色系：#E6E6FA (薰衣草) / #DDA0DD (梅红) / #9370DB (中紫)
💙 蓝色系：#87CEEB (天蓝) / #ADD8E6 (浅蓝) / #B0E0E6 (粉蓝)
💛 黄色系：#FFFACD (柠檬绸) / #FFEFD5 (木瓜色) / #FFE4B5 (鹿皮色)
💚 绿色系：#98FB98 (浅绿) / #90EE90 (淡绿) / #8FBC8F (海绿)
```

### 色彩情绪对应
| 情绪 | 色彩 | 应用场景 |
|------|------|---------|
| 开心 | 粉色+黄色 | 消除成功、奖励获得 |
| 平静 | 蓝色+绿色 | 花园场景、休息时刻 |
| 治愈 | 紫色+粉色 | 剧情对话、故事解锁 |
| 温暖 | 橙色+黄色 | 好友互动、赠送星光 |
| 梦幻 | 彩虹渐变 | 特殊关卡、星光爆发 |

## 📱 社交系统设计

### 微信生态整合

#### 游戏圈运营
- **互助专区**：赠送星光、交换花语碎片

- **邀请好友**：获得限定星光花园装饰
- **分享解锁**：分享解锁隐藏花语

### 轻社交互动
- **好友花园**：参观、点赞、赠送星光
- **花语赠送**：向好友赠送代表情绪的花朵
- **治愈日记**：分享今日治愈时刻
