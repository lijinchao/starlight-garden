## 1. 迭代目标

本轮只做一件事：

> 让玩家把收获得到的星光转化为花园内可见的装饰变化，补齐“消除 -> 奖励 -> 合成/收获 -> 装饰”的最小主循环。

本轮不做：

- 自由拖拽摆放
- 大型装饰图鉴
- 主题皮肤与季节活动
- 好友拜访、分享截图、排行榜
- 广告 SDK 或付费礼包接入

---

## 2. 服务的产品目标

本轮选择：

- 闭合主循环
- 强化局外成长
- 优化资源反哺

原因：

- 当前星光已经能用于续关和开局祝福，但缺少“让花园变好看”的局外成长目标。
- 花园装饰能把玩家多打一局、收获花朵、积累星光的行为变成可见结果。
- 本轮只做固定装饰位和氛围值，不扩展外围社交系统，避免偏离主循环。

---

## 3. 用户感知目标

玩家完成一次或多次体验后，应能明确感知：

1. 花园中出现“花园装饰”区域。
2. 星光可以购买长椅、星灯、小喷泉、花篱等装饰。
3. 已购买装饰会被点亮，并提升花园氛围值。
4. 花园不再只负责生产星光，也能消耗星光形成长期目标。

---

## 4. 功能项与目标映射

| 功能项 | 服务的产品目标 | 玩家可感知变化 | 验证方式 |
|------|------|------|------|
| 装饰服务 | 闭合主循环 / 强化局外成长 | 星光可购买装饰并写入存档 | 自动化测试 |
| 固定装饰目录 | 强化局外成长 | 花园有明确可追逐目标 | 自动化测试 + 手动验证 |
| 氛围值 | 优化资源反哺 | 已购买装饰形成累计成长反馈 | 自动化测试 + 手动验证 |
| 花园 UI 接入 | 强化局外成长 | 玩家在花园页直接看到装饰状态 | 手动验证 |
| Harness 扩展 | 确保方向正确 | 后续迭代不能绕过装饰闭环验证 | Harness 检查 |

## 5. 功能定义

### P1-1 装饰服务

目标：

- 提供固定装饰目录、购买、已拥有判断、氛围值计算。

产品目标对应：

- 闭合主循环
- 强化局外成长

实现要求：

- 新增 `DecorationService` 自动加载服务。
- 装饰目录至少包含 4 个固定装饰。
- 购买装饰消耗星光。
- 已购买装饰写入 `garden.decorations`。
- 重复购买同一装饰失败，不重复扣费。
- 星光不足时购买失败，不改写存档。

验收标准：

- 星光足够时购买成功并扣除对应星光。
- 星光不足、重复购买、非法装饰 ID 都会返回失败原因。
- 重置存档后装饰为空，氛围值为 `0`。

可评估结果：

- 玩家多打一局、收获花朵后，能把星光投入花园外观成长。

### P1-2 花园装饰 UI

目标：

- 玩家在“我的花园”中直接看到可购买装饰、已拥有状态和氛围值。

产品目标对应：

- 强化局外成长
- 优化资源反哺

实现要求：

- 花园页增加“花园装饰”区域。
- 展示当前氛围值。
- 展示每个装饰的名称、消耗、氛围加成。
- 未拥有装饰显示购买按钮。
- 已拥有装饰显示已点亮状态。

验收标准：

- 进入花园即可看到装饰区域。
- 星光足够时点击购买后状态立即变为已点亮。
- 星光不足时出现明确提示。
- 返回再进入花园，已购买状态仍保持。

可评估结果：

- 如果移除装饰 UI，星光缺少局外长期消耗目标，主循环追求感变弱。

## 6. 数据与资源流

本轮资源流：

`闯关 -> 获得花种/星光 -> 花园种植/收获 -> 获得更多星光 -> 购买花园装饰 -> 提升氛围值`

资源来源：

- 通关奖励星光
- 失败保底星光
- 花园收获星光
- 今日花礼星光

资源用途：

- 续关
- 开局祝福
- 花园装饰购买

资源反馈：

- 花园页展示已点亮装饰。
- 花园页展示氛围值。
- 购买后 Toast 明确提示结果。

---

## 7. UI / 交互要求

- 装饰入口放在“我的花园”页内，不新增主菜单入口。
- 装饰使用固定列表，不提供拖拽摆放。
- 购买失败必须显示原因。
- 已购买装饰不可重复购买。
- UI 文案保持治愈、低压力，不使用强促销表达。

---

## 8. 验证清单

### 自动化测试

- 装饰目录存在且至少 4 个。
- 默认存档装饰为空，氛围值为 `0`。
- 星光不足时购买失败且不写入装饰。
- 星光足够时购买成功、扣除星光、写入存档。
- 重复购买同一装饰失败且不重复扣费。
- 非法装饰 ID 购买失败。

### 手动验证

- 进入“我的花园”，看到花园装饰区域和氛围值。
- 星光不足时点击购买，看到星光不足提示。
- 获得足够星光后购买装饰。
- 购买后按钮变为“已点亮”，氛围值提升。
- 返回主菜单再进入花园，装饰状态保持。

### 评估问题

1. 玩家是否能理解星光除了局内帮助外，还能改变花园？
2. 装饰是否让“再打一局拿星光”更有理由？
3. 氛围值是否提供了清晰的长期累计反馈？
4. 如果移除装饰购买，主循环是否明显回退到半闭合？
