## 1. 调研结论

当前棋盘每关只有“交换三连、累计一种花”的数值变化，四连清风也只额外增加目标数值。玩家无需改变观察方式，因此换目标花和减少步数只会增加难度，不会增加新鲜感。

外部产品给出的共同启发：

- `Royal Match` 的基础交换不复杂，关卡变化主要来自目标元素和障碍之间的空间关系。
- `Two Dots` 用同一连接手势产生“线”和“方形”两种结果，让形状本身成为决策。
- `Best Fiends` 让玩家规划更长路径，长度直接改变收益。
- `Pokémon Café ReMix` 保持单指连接，但让不同机关需要不同的空间处理方式，并受有限步数约束。
- 2025 年 Puzzle 市场研究仍强调简单核心与更深层变化的结合；对本项目而言，应先加强每一步的局面意义，而不是继续扩 Meta。

## 2. 迭代目标

产品目标：让玩家在保持传统交换操作零学习成本的同时，开始考虑消除的位置与方向。

核心规则：

1. 棋盘上覆盖少量落叶，但落叶不锁死棋子，也不增加点击规则。
2. 任意三连会扫开匹配位置自身及上下左右相邻的落叶，保证稳定推进。
3. 四连会按匹配方向形成清风路径，额外扫开整行或整列上的落叶。
4. 收集目标和落叶目标同时完成才通关。

用户感知：三连是可靠的小进展，四连是可规划的大清场；横四连与竖四连不再等价。

## 3. 本轮不做

- 不增加炸弹、彩球、火箭或多套特殊棋子。
- 不增加新的局内货币、英雄、技能树或随机卡牌。
- 不让落叶阻止交换，避免前五关认知负担过高。
- 不用纯随机四连作为唯一通关条件。
- 试玩记录继续只保存在本地，不联网、不收集个人信息。

## 4. 目标映射

| 功能项 | 服务的产品目标 | 用户可感知结果 | 验证方式 |
|--------|----------------|----------------|----------|
| 相邻清扫 | 提供稳定进度 | 普通三连也能处理落叶 | 规则测试 |
| 方向清风 | 增加空间决策 | 横四连与竖四连结果不同 | 规则测试 + 试玩 |
| 落叶布局 | 形成关卡变化 | 每关关注区域不同 | 配置检查 + 截图 |
| 双目标 HUD | 保持挑战可理解 | 同时看懂收花与扫叶进度 | 自动化 + 截图 |
| 路径动画 | 强化爽点和因果 | 能指出哪条清风扫掉了落叶 | 视觉检查 + 试玩 |

## 5. 分阶段目标

### K-1 规则垂直切片

- 第 1 关保留纯收集教学。
- 第 2-5 关逐步增加 3、4、5、6 处落叶，并使用不同空间布局。
- 普通匹配邻近清扫、四连方向路径和双目标胜负均有自动化测试。
- 真实 `750 x 1334` 视口中，落叶不遮挡花朵识别、HUD 不遮挡棋盘。

实现结果（2026-08-15）：

- 第 2-5 关已接入 3、4、5、6 处不同落叶布局。
- 普通三连相邻清扫、横纵四连路径、双目标胜负和十字误判保护均已实现。
- Harness `197/197`、Godot 自动化测试 `422/422` 通过。
- 已检查落叶初始布局和横向清风两个真实 `750 x 1334` 渲染状态。

### K-2 目标用户试玩

至少 5 名目标用户无讲解体验前 5 关。

可评估门槛：

- 至少 4/5 能在第 2 关理解“在落叶旁消除”。
- 至少 3/5 在第 3-5 关主动尝试用四连方向扫叶。
- 至少 4/5 能说出两局之间不只是目标数字不同。
- 至少 3/5 认为清风路径既有帮助又需要思考。
- 若四连识别低于 3/5，优先调整布局与反馈，不增加教程弹窗或新特殊块。

## 6. 完成定义

规则、配置、视觉、自动化和真实视口检查全部通过，只代表 K-1 工程完成。达到 K-2 的观察门槛后，才判定该创新值得扩展到后续关卡；否则回退或重做，不继续增加局内系统。
