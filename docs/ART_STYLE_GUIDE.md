## 🌸 元素设计

### 消除元素（花朵）

| 元素 | 颜色 | 形状特征 |
|------|------|---------|
| 红玫瑰 | #FF6B6B | 螺旋花瓣，金色花蕊 |
| 蓝勿忘我 | #74B9FF | 5片花瓣，黄色花蕊 |
| 紫薰衣草 | #A29BFE | 穗状花序，绿色茎干 |
| 黄向日葵 | #FDCB6E | 放射状花瓣，棕色花盘 |
| 白茉莉 | #DFE6E9 | 多层花瓣，珍珠光泽 |
| 粉樱花 | #FD79A8 | 心形花瓣，粉色渐变 |

### 特殊元素
```
流星：金色拖尾，从中心向外扩散
彩虹花：七色渐变，旋转光效
星光炸弹：扩散光波，花瓣四散
```

### 设计原则
- **造型**：圆润可爱，避免尖锐棱角
- **质感**：半透明+光泽感，类似糖果/宝石
- **动态**：轻微摇曳，消除时绽放+粒子飘散

## ✨ 特效设计

### 消除特效
```
1. 花朵放大1.2倍
2. 绽放光效（向外扩散）
3. 花瓣四散飘落
4. 星光粒子上升
5. 消失（渐隐）
```

### 连锁特效
```
1. 触发花朵高亮
2. 连线光效（金色）
3. 同时绽放
4. 星光雨落下
5. 屏幕轻微震动+闪光
```

### 合成特效
```
1. 两个花朵靠近
2. 融合光效（漩涡）
3. 新花朵从光中诞生
4. 播放治愈音效
5. 星光粒子环绕
```

### 治愈时刻
```
1. 屏幕渐变为暖色调
2. 大量花瓣从天空飘落
3. 背景音乐变为治愈BGM
4. 中央花朵绽放特写
5. 显示治愈语录
6. 奖励弹出
```
